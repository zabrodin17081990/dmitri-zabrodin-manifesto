# 作为信息过程的意识

意识是一个离散的、预测性的信息处理系统，具有反馈回路并能够建模周围世界（包括自身的某些方面）。

## 预测回路

任何具有反馈的预测系统都会形成一个**循环**：要预测未来，系统必须考虑它自身的未来动作。而这些动作又依赖于预测。这将系统封闭为一个递归的**回路**，在其中因果关系不断互换位置。

- 预测决定行动
- 行动改变未来
- 改变的未来需要新的预测
- 新的预测再次决定行动……

为了使这样的**回路**成为**有效产出**而不是无限自我复制，系统需要一个基本的划分：

- **"自我"模型**——系统认为是自己的并能直接控制的东西（身体、注意力焦点、意图）。
- **"世界"模型**——影响系统的一切，但只能通过自我的行动间接影响。

这种划分允许从简单循环过渡到有意义的建模："如果**我**执行动作 A，那么**世界**很可能以方式 B 改变，反过来这将以方式 C 影响我"。

## 递归作为意识的本质

将现实拆分为"自我"与"世界"使得递归更可控且有产出：

**我改变世界 → 世界改变我 → 我被改变后再次改变世界 → ...**

## 递归深度

活跃注意区越大，系统能建模的相互影响链越深：

- **1级**："我做 A → 结果是 B"
- **2级**："我做 A → 结果是 B → 这改变了我 → 我将能做 C"
- **N 级**：考虑自身变化的多步策略

内部容量（dim(inner)）的富余允许：
- 成功建模不可预见的情形
- 找到实现旧目标的新或更优途径
- 在不行动的情况下学习（用理论代替潜在危险的实践）
- 分析系统未实现的可能性
